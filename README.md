Hi, I'm Aryanna.
================

I build websites, automation, and small tools at Bloomwired.

My open-source projects help AI coding assistants work with slow internet, limited hardware, restricted permissions, and Windows.

Projects
--------

- [My Internet Sucks](https://github.com/aryannaio/my-internet-sucks-agent-skill) helps coding agents save progress and plan network work around unreliable connections.
- [Potato Mode](https://github.com/aryannaio/potato-mode-agent-skill) checks memory, disk space, and CPU capacity before an agent starts heavy work.
- [No Admin Access](https://github.com/aryannaio/no-admin-access-agent-skill) helps agents use project-local tools on computers without administrator access.
- [I'm on Windows](https://github.com/aryannaio/im-on-windows-agent-skill) helps agents keep shells, paths, and runtimes consistent on Windows.

These are early projects for Claude Code and Codex. All four use the MIT license. Reproducible bug reports, tests on different computers, and clear documentation improvements are welcome. Each repository has a contribution guide.
